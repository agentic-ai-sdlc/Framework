# Modular Code Structure

When building production-grade systems, adopt a Modular Architecture approach. This means separating different components or features of the application into distinct modules. By doing so, it becomes easier to maintain, test, and update individual parts without impacting the entire system.

This directory structure should follow a generic best-practice pattern that is used in many agentic systems or even in pure software engineering., each folder has a specific purpose, like Feature-Sliced Design (FSD) architecture. Instead of grouping files by type (e.g., putting all components in one folder and all pages in another), group them by business domain.
